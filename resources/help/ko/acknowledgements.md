# 감사의 글

Muffin은 훌륭한 오픈 소스 프로젝트들의 어깨 위에 서 있습니다.

## 핵심 라이브러리

- [Qt 6](https://www.qt.io) — 애플리케이션 및 UI 프레임워크.
- [cmark‑gfm](https://github.com/github/cmark-gfm) — GitHub‑Flavored Markdown 파싱.
- [Tree‑sitter](https://tree-sitter.github.io) 및 언어 문법들 — 코드 구문 강조.
- [KaTeX](https://katex.org) — 빠른 수식 조판(글꼴 포함).
- [Nuspell](https://github.com/nuspell/nuspell) — 맞춤법 검사.
- [ICU](https://icu.unicode.org) — 유니코드 지원.

## 레이아웃과 HTML

- [Yoga](https://github.com/facebook/yoga) — 플렉스박스 레이아웃 엔진.
- [Lexbor](https://github.com/lexbor/lexbor) — HTML 파싱.

## 이미지 디코딩

- [libavif](https://github.com/AOMediaCodec/libavif) 및 [dav1d](https://code.videolan.org/videolan/dav1d) — AVIF 이미지 디코딩.
- [libjpeg](https://www.ijg.org) — JPEG 디코딩.
- [libpng](https://www.libpng.org/pub/png/libpng.html) — PNG 디코딩.
- [libwebp](https://developers.google.com/speed/webp) — WebP 디코딩.

## 맞춤법 검사 사전

번들된 사전은 [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries)(영어는 [SCOWL](http://wordlist.aspell.net/) 기반) 및 [wooorm/dictionaries](https://github.com/wooorm/dictionaries)(기타 언어)에서 가져왔습니다.

## 감사

Muffin을 더 낫게 만들어 주시는 모든 번역자, 테스터, 기여자 분들께 감사드립니다. [이슈 트래커](https://github.com/jstzwj/Muffin/issues)에서 피드백을 환영합니다.

[프로젝트 홈페이지](https://github.com/jstzwj/Muffin)를 방문하시거나 [빠른 시작](help:quick-start)으로 돌아가세요.
