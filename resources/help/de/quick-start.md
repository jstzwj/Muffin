# Schnellstart

Willkommen bei **Muffin**, einem schnellen, nativen Markdown-Editor, der mit C++ und Qt entwickelt wurde.

## Dokument erstellen oder öffnen

- Wählen Sie **Datei → Neu** für ein leeres Dokument oder **Datei → Öffnen**, um eine bestehende `.md`-Datei zu öffnen.
- **Datei → Ordner öffnen** öffnet einen Ordner in der Seitenleiste, sodass Sie Dateien durchsuchen und wechseln können.

## Zwei Bearbeitungsmodi

- Der **Rendermodus** (Standard) zeigt eine formatierte Live-Seite — Markdown tippen, Ergebnis sofort sehen.
- Der **Quelltextmodus** zeigt den reinen Markdown-Text. Schalten Sie ihn über das Menü **Ansicht** um.

## Ihr erstes Dokument schreiben

Tippen Sie Markdown, und es wird sofort formatiert. Ein paar Grundlagen:

| Sie tippen | Sie erhalten |
| --- | --- |
| `# Überschrift` | Eine Überschrift der Ebene 1 |
| `**fett**` / `*kursiv*` | **fett** / *kursiv* |
| `- Eintrag` | Eine Aufzählungsliste |
| `` `Code` `` | Inline-`Code` |
| `[Link](https://example.com)` | Ein klickbarer Link |

Fügen Sie Tabellen, Mathe (`$E=mc^2$`), Fußnoten und Codeblöcke ein — Muffin rendert den gesamten GitHub-Flavored Markdown.

## Tipps

- Nutzen Sie die Einträge „Format" und „Absatz" in den Menüs, um Text zu gestalten, ohne sich Syntax merken zu müssen.
- **Bearbeiten → Suchen / Ersetzen** durchsucht das aktuelle Dokument.
- Wählen Sie ein Erscheinungsbild unter **Design** — Muffin wird mit hellen, dunklen und „Whitey"-Designs ausgeliefert.

Die vollständige Syntaxreferenz finden Sie in der [Markdown-Referenz](help:markdown-reference).

Wer Muffin möglich macht, erfahren Sie in den [Danksagungen](help:acknowledgements).
