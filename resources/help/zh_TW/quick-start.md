# 快速入門

歡迎使用 **Muffin**，一款以 C++ 與 Qt 打造的快速、原生 Markdown 編輯器。

## 新增或開啟文件

- 選擇 **檔案 → 新增** 建立一份空白文件，或選擇 **檔案 → 開啟** 開啟現有的 `.md` 檔案。
- **檔案 → 開啟資料夾** 可在側邊欄開啟資料夾，方便您瀏覽與切換檔案。
- **檔案 → 重新開啟已關閉的檔案**（`Ctrl+Shift+T`，macOS 為 `⌘+Shift+T`）可恢復最近關閉檔案的編輯模式、選取範圍及閱讀位置。每個視窗最多記住 32 個檔案，結束視窗後清空。重新開啟會讀取磁碟上的最新內容，不會恢復已捨棄的未儲存修改。

## 兩種編輯模式

- **渲染模式**（預設）顯示即時格式化的頁面 —— 輸入 Markdown，即可看到效果。
- **原始碼模式** 顯示原始的 Markdown 文字。可從 **檢視** 選單中切換。

## 撰寫您的第一份文件

輸入 Markdown 即可即時格式化。以下是幾個基本要素：

| 您輸入的 | 您得到的效果 |
| --- | --- |
| `# 標題` | 一級標題 |
| `**粗體**` / `*斜體*` | **粗體** / *斜體* |
| `- 項目` | 無序清單 |
| `` `程式碼` `` | 行內 `程式碼` |
| `[連結](https://example.com)` | 可點擊的連結 |

您還可以插入表格、數學公式（`$E=mc^2$`）、註腳以及程式碼區塊 —— Muffin 支援渲染完整的 GitHub 風格 Markdown。

## 匯出預設組與重複匯出

在 **偏好設定 → 匯出** 按 **新增**，可依 PDF、HTML、圖片、Pandoc 格式或 **自訂命令** 建立具名預設組。每個預設組獨立儲存參數，可複製、重新命名、排序或移除，原有格式的預設設定仍然保留。從 **檔案 → 匯出 → 匯出預設組** 選擇即可匯出。

成功匯出後，**使用上次設定匯出** 沿用該次參數並讓您選擇新位置；**匯出並覆寫上次輸出** 直接寫入上次成功的目標檔案。兩者皆匯出目前內文，包括未儲存的修改。每個分頁獨立記住上次成功的參數及實際佈景主題，關閉分頁後清空。失敗或取消會保留原輸出檔及上次成功記錄。這些命令也能在 **偏好設定 → 鍵盤快捷鍵** 中設定快捷鍵。

自訂命令需填入可執行程式、參數及不含點號的輸出副檔名。程式必須在 `${outputPath}` 產生單一檔案。參數可使用 `${inputPath}`（包含未儲存修改的臨時 UTF-8 Markdown 副本）、`${outputPath}`（臨時輸出路徑，成功後由 Muffin 寫入目標）、`${currentPath}`（目前文件路徑，未命名時為空）、`${currentFolder}`（文件資料夾，未命名時使用使用者家目錄）及 `${fileName}`（不含副檔名的文件名稱）。

例如，選擇 Pandoc 為可執行程式後，可填入：`"${inputPath}" -o "${outputPath}" -t docx`。含空格的參數請用雙引號包圍；變數以字面內容傳遞，不會自動啟動命令列 shell。如需範本、目錄等內建格式選項，可直接建立相應 Pandoc 格式的預設組。

## 實用技巧

- 使用選單中的「格式」與「段落」項目為文字套用樣式，無須記憶語法。
- **編輯 → 尋找 / 取代** 可在目前文件中搜尋。
- 在 **佈景主題** 中挑選外觀 —— Muffin 內建淺色、深色以及「Whitey」三種佈景主題。

完整的語法參考請查閱 [Markdown 參考手冊](help:markdown-reference)。

了解讓 Muffin 得以實現的貢獻者，請閱讀 [致謝](help:acknowledgements)。
