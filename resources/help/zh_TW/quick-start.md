# 快速開始

歡迎使用 **Muffin**，一款以 C++ 與 Qt 打造的快速、原生 Markdown 編輯器。

## 新增或開啟文件

- 選擇 **檔案 → 新增** 建立一份空白文件，或選擇 **檔案 → 開啟** 開啟現有的 `.md` 檔案。
- **檔案 → 開啟資料夾** 可在側邊欄開啟資料夾，方便您瀏覽與切換檔案。

## 兩種編輯模式

- **渲染模式**（預設）顯示即時格式化的頁面 —— 輸入 Markdown，即可看到效果。
- **原始碼模式** 顯示原始的 Markdown 文字。可從 **檢視** 選單中切換。

## 撰寫您的第一份文件

輸入 Markdown 即可即時格式化。以下是幾個基本要素：

| 您輸入的 | 您得到的效果 |
| --- | --- |
| `# 標題` | 一級標題 |
| `**粗體**` / `*斜體*` | **粗體** / *斜體* |
| `- 項目` | 無序清單 |
| `` `程式碼` `` | 行內 `程式碼` |
| `[連結](https://example.com)` | 可點擊的連結 |

您還可以插入表格、數學公式（`$E=mc^2$`）、註腳以及程式碼區塊 —— Muffin 支援渲染完整的 GitHub 風格 Markdown。

## 實用技巧

- 使用選單中的「格式」與「段落」項目為文字套用樣式，無須記憶語法。
- **編輯 → 尋找 / 取代** 可在目前文件中搜尋。
- 在 **佈景主題** 中挑選外觀 —— Muffin 內建淺色、深色以及「Whitey」三種佈景主題。

完整的語法參考請查閱 [Markdown 參考手冊](help:markdown-reference)。
