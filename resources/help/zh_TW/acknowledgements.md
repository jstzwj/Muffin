# 致謝

Muffin 站在眾多優秀開源專案的肩膀上。

## 核心函式庫

- [Qt 6](https://www.qt.io) —— 應用程式與介面框架。
- [cmark‑gfm](https://github.com/github/cmark-gfm) —— GitHub 風格 Markdown 解析。
- [Tree‑sitter](https://tree-sitter.github.io) 及其語言文法 —— 程式碼語法高亮。
- [KaTeX](https://katex.org) —— 快速數學公式排版（內附字型）。
- [Nuspell](https://github.com/nuspell/nuspell) —— 拼寫檢查。
- [ICU](https://icu.unicode.org) —— Unicode 支援。

## 版面與 HTML

- [Yoga](https://github.com/facebook/yoga) —— Flexbox 版面引擎。
- [Lexbor](https://github.com/lexbor/lexbor) —— HTML 解析。

## 影像解碼

- [libavif](https://github.com/AOMediaCodec/libavif) 與 [dav1d](https://code.videolan.org/videolan/dav1d) —— AVIF 影像解碼。
- [libjpeg](https://www.ijg.org) —— JPEG 解碼。
- [libpng](https://www.libpng.org/pub/png/libpng.html) —— PNG 解碼。
- [libwebp](https://developers.google.com/speed/webp) —— WebP 解碼。

## 拼寫檢查詞典

內附詞典取自 [LibreOffice 詞典](https://github.com/LibreOffice/dictionaries)（英文部分基於 [SCOWL](http://wordlist.aspell.net/)）以及 [wooorm/dictionaries](https://github.com/wooorm/dictionaries)（其它語言）。
