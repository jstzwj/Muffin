# 謝辞

Muffin は、優れたオープンソースプロジェクトの上に成り立っています。

## コアライブラリー

- [Qt 6](https://www.qt.io) — アプリケーションおよび UI フレームワーク。
- [cmark‑gfm](https://github.com/github/cmark-gfm) — GitHub‑Flavored Markdown の解析。
- [Tree‑sitter](https://tree-sitter.github.io) およびその各言語文法 — コードのシンタックスハイライト。
- [KaTeX](https://katex.org) — 高速な数式組版（フォント同梱）。
- [Nuspell](https://github.com/nuspell/nuspell) — スペルチェック。
- [ICU](https://icu.unicode.org) — Unicode サポート。

## レイアウトと HTML

- [Yoga](https://github.com/facebook/yoga) — フレックスボックスレイアウトエンジン。
- [Lexbor](https://github.com/lexbor/lexbor) — HTML 解析。

## 画像デコード

- [libavif](https://github.com/AOMediaCodec/libavif) および [dav1d](https://code.videolan.org/videolan/dav1d) — AVIF 画像のデコード。
- [libjpeg](https://www.ijg.org) — JPEG のデコード。
- [libpng](https://www.libpng.org/pub/png/libpng.html) — PNG のデコード。
- [libwebp](https://developers.google.com/speed/webp) — WebP のデコード。

## スペルチェック辞書

同梱の辞書は、[LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries)（英語は [SCOWL](http://wordlist.aspell.net/) ベース）および [wooorm/dictionaries](https://github.com/wooorm/dictionaries)（その他の言語）を元にしています。
