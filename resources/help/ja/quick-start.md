# クイックスタート

C++ と Qt で作られた、高速でネイティブな Markdown エディター **Muffin** へようこそ。

## ドキュメントを作成・開く

- 新しい空のドキュメントを作るには **ファイル → 新規**、既存の `.md` ファイルを開くには **ファイル → 開く** を選びます。
- **ファイル → フォルダーを開く** でサイドバーにフォルダーを表示し、ファイルを参照しながら切り替えられます。

## 2 つの編集モード

- **レンダーモード**（既定）は、整形済みのページをリアルタイムで表示します。Markdown を入力すると、すぐに結果が反映されます。
- **ソースモード** は、生の Markdown テキストを表示します。**表示** メニューから切り替えられます。

## 最初のドキュメントを書く

Markdown を入力すると、即座に整形されます。基本となる記法は以下のとおりです。

| 入力 | 結果 |
| --- | --- |
| `# Heading` | レベル 1 の見出し |
| `**bold**` / `*italic*` | **bold** / *italic* |
| `- item` | 箇条書きリスト |
| `` `code` `` | インライン `code` |
| `[link](https://example.com)` | クリックできるリンク |

表、数式（`$E=mc^2$`）、脚注、コードブロックも挿入できます。Muffin は GitHub‑Flavored Markdown のすべてをレンダリングします。

## ヒント

- メニューの整形や段落の項目を使えば、記法を覚えなくても文字のスタイルを設定できます。
- **編集 → 検索 / 置換** で現在のドキュメントを検索できます。
- **テーマ** で見た目を選べます。Muffin にはライト、ダーク、"Whitey" のテーマが用意されています。

記法の完全なリファレンスは、[Markdown リファレンス](help:markdown-reference) をご覧ください。

Muffin を支えてくれている方々については、[謝辞](help:acknowledgements) をお読みください。
