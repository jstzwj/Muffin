# Agradecimentos

O Muffin apoia‑se em projetos de código aberto excelentes.

## Bibliotecas principais

- [Qt 6](https://www.qt.io) — framework de aplicação e interface.
- [cmark‑gfm](https://github.com/github/cmark-gfm) — análise de GitHub‑Flavored Markdown.
- [Tree‑sitter](https://tree-sitter.github.io) e suas gramáticas de linguagem — realce de sintaxe de código.
- [KaTeX](https://katex.org) — composição tipográfica rápida de matemática (fontes incluídas).
- [Nuspell](https://github.com/nuspell/nuspell) — verificação ortográfica.
- [ICU](https://icu.unicode.org) — suporte a Unicode.

## Layout e HTML

- [Yoga](https://github.com/facebook/yoga) — motor de layout flexbox.
- [Lexbor](https://github.com/lexbor/lexbor) — análise de HTML.

## Decodificação de imagens

- [libavif](https://github.com/AOMediaCodec/libavif) e [dav1d](https://code.videolan.org/videolan/dav1d) — decodificação de imagens AVIF.
- [libjpeg](https://www.ijg.org) — decodificação JPEG.
- [libpng](https://www.libpng.org/pub/png/libpng.html) — decodificação PNG.
- [libwebp](https://developers.google.com/speed/webp) — decodificação WebP.

## Dicionários de verificação ortográfica

Os dicionários incluídos vêm de [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries) (e [SCOWL](http://wordlist.aspell.net/) para o inglês) e de [wooorm/dictionaries](https://github.com/wooorm/dictionaries) para os demais idiomas.

## Agradecimentos

Nosso agradecimento a cada tradutor, testador e colaborador que ajuda a melhorar o Muffin. Seus comentários são bem‑vindos no [rastreador de problemas](https://github.com/jstzwj/Muffin/issues).

Visite a [página do projeto](https://github.com/jstzwj/Muffin) ou volte para o [Início rápido](help:quick-start).
