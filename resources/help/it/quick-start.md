# Avvio rapido

Benvenuto in **Muffin**, un editor Markdown veloce e nativo, realizzato in C++ e Qt.

## Creare o aprire un documento

- Scegli **File → Nuovo** per un documento vuoto, oppure **File → Apri** per aprire un file `.md` esistente.
- **File → Apri cartella** apre una cartella nella barra laterale, così puoi esplorare e cambiare file.

## Due modalità di modifica

- La **modalità di rendering** (predefinita) mostra una pagina formattata in tempo reale — scrivi Markdown e vedi subito il risultato.
- La **modalità sorgente** mostra il testo Markdown grezzo. Puoi attivarla dal menu **Visualizza**.

## Scrivi il tuo primo documento

Scrivi Markdown e viene formattato all'istante. Qualche elemento essenziale:

| Cosa scrivi | Cosa ottieni |
| --- | --- |
| `# Titolo` | Un titolo di livello 1 |
| `**grassetto**` / `*corsivo*` | **grassetto** / *corsivo* |
| `- elemento` | Un elenco puntato |
| `` `codice` `` | `codice` in linea |
| `[collegamento](https://example.com)` | Un collegamento cliccabile |

Inserisci tabelle, formule (`$E=mc^2$`), note a piè di pagina e blocchi di codice — Muffin rende l'intero GitHub-Flavored Markdown.

## Suggerimenti

- Usa le voci "Formato" e "Paragrafo" nei menu per applicare gli stili senza dover ricordare la sintassi.
- **Modifica → Trova / Sostituisci** effettua la ricerca nel documento corrente.
- Scegli un aspetto in **Tema** — Muffin include i temi chiaro, scuro e "Whitey".

Per il riferimento completo alla sintassi, vedi la [Guida di riferimento Markdown](help:markdown-reference).

Per scoprire chi rende possibile Muffin, leggi i [Ringraziamenti](help:acknowledgements).
