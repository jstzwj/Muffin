# Acknowledgements

Muffin stands on the shoulders of excellent open‑source projects.

## Core libraries

- [Qt 6](https://www.qt.io) — application and UI framework.
- [cmark‑gfm](https://github.com/github/cmark-gfm) — GitHub‑Flavored Markdown parsing.
- [Tree‑sitter](https://tree-sitter.github.io) and its language grammars — code syntax highlighting.
- [KaTeX](https://katex.org) — fast math typesetting (fonts bundled).
- [Nuspell](https://github.com/nuspell/nuspell) — spell checking.
- [ICU](https://icu.unicode.org) — Unicode support.

## Layout and HTML

- [Yoga](https://github.com/facebook/yoga) — flexbox layout engine.
- [Lexbor](https://github.com/lexbor/lexbor) — HTML parsing.

## Image decoding

- [libavif](https://github.com/AOMediaCodec/libavif) and [dav1d](https://code.videolan.org/videolan/dav1d) — AVIF image decoding.
- [libjpeg](https://www.ijg.org) — JPEG decoding.
- [libpng](https://www.libpng.org/pub/png/libpng.html) — PNG decoding.
- [libwebp](https://developers.google.com/speed/webp) — WebP decoding.

## Spell‑check dictionaries

The bundled dictionaries draw on [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries) (and [SCOWL](http://wordlist.aspell.net/) for English) and [wooorm/dictionaries](https://github.com/wooorm/dictionaries) for other locales.

## Thanks

Thank you to every translator, tester, and contributor who helps make Muffin better. Your feedback is welcome on the [issue tracker](https://github.com/jstzwj/Muffin/issues).
