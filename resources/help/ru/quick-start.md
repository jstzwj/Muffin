# Быстрый старт

Добро пожаловать в **Muffin** — быстрый, нативный редактор Markdown, созданный на C++ и Qt.

## Создание или открытие документа

- Выберите **Файл → Создать** для пустого документа или **Файл → Открыть**, чтобы открыть существующий файл `.md`.
- **Файл → Открыть папку** открывает папку на боковой панели, чтобы вы могли просматривать и переключаться между файлами.

## Два режима редактирования

- **Режим разметки** (по умолчанию) показывает страницу с живым форматированием — вводите Markdown и сразу видите результат.
- **Режим исходного кода** показывает исходный текст Markdown. Переключите его через меню **Вид**.

## Напишите свой первый документ

Вводите Markdown, и текст форматируется мгновенно. Вот несколько основ:

| Вы вводите | Получаете |
| --- | --- |
| `# Заголовок` | Заголовок уровня 1 |
| `**полужирный**` / `*курсив*` | **полужирный** / *курсив* |
| `- элемент` | Маркированный список |
| `` `код` `` | Строчный `код` |
| `[ссылка](https://example.com)` | Кликабельная ссылка |

Вставляйте таблицы, математику (`$E=mc^2$`), сноски и блоки кода — Muffin отображает весь GitHub‑Flavored Markdown.

## Советы

- Используйте пункты «Формат» и «Абзац» в меню, чтобы стилизовать текст, не запоминая синтаксис.
- **Правка → Найти / Заменить** выполняет поиск по текущему документу.
- Выберите оформление в разделе **Тема** — Muffin поставляется со светлой, тёмной темами и темой «Whitey».

Полный справочник по синтаксису см. в [Справочнике Markdown](help:markdown-reference).

Чтобы узнать, кто делает Muffin возможным, прочитайте [Благодарности](help:acknowledgements).
