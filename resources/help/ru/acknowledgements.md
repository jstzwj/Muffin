# Благодарности

Muffin стоит на плечах отличных проектов с открытым исходным кодом.

## Основные библиотеки

- [Qt 6](https://www.qt.io) — фреймворк для приложений и пользовательских интерфейсов.
- [cmark‑gfm](https://github.com/github/cmark-gfm) — разбор GitHub‑Flavored Markdown.
- [Tree‑sitter](https://tree-sitter.github.io) и его грамматики языков — подсветка синтаксиса кода.
- [KaTeX](https://katex.org) — быстрая вёрстка математики (шрифты в комплекте).
- [Nuspell](https://github.com/nuspell/nuspell) — проверка орфографии.
- [ICU](https://icu.unicode.org) — поддержка Юникода.

## Вёрстка и HTML

- [Yoga](https://github.com/facebook/yoga) — движок flexbox‑вёрстки.
- [Lexbor](https://github.com/lexbor/lexbor) — разбор HTML.

## Декодирование изображений

- [libavif](https://github.com/AOMediaCodec/libavif) и [dav1d](https://code.videolan.org/videolan/dav1d) — декодирование изображений AVIF.
- [libjpeg](https://www.ijg.org) — декодирование JPEG.
- [libpng](https://www.libpng.org/pub/png/libpng.html) — декодирование PNG.
- [libwebp](https://developers.google.com/speed/webp) — декодирование WebP.

## Словари для проверки орфографии

Встроенные словари основаны на [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries) (и [SCOWL](http://wordlist.aspell.net/) для английского), а также на [wooorm/dictionaries](https://github.com/wooorm/dictionaries) для других языков.

Спасибо каждому переводчику, тестировщику и участнику, кто помогает делать Muffin лучше. Ваши отзывы ждут в [баг‑трекере](https://github.com/jstzwj/Muffin/issues).
