# Справочник Markdown

Muffin отображает **GitHub‑Flavored Markdown (GFM)**. Это краткий справочник по возможностям редактора.

## Заголовки

```
# Heading 1
## Heading 2
### Heading 3
```

Поддерживается до шести уровней.

## Выделение

```
**bold**   *italic*   ***both***   ~~strikethrough~~
```

**bold** *italic* ***both*** ~~strikethrough~~

## Списки

Ненумерованные списки используют `-`, `*` или `+`:

```
- Apples
- Oranges
  - Tangerines
```

Нумерованные списки используют числа:

```
1. First
2. Second
```

Списки задач превращаются в флажки:

```
- [x] Done
- [ ] To do
```

- [x] Done
- [ ] To do

## Ссылки и изображения

```
[text](https://example.com)
![alt text](image.png)
```

Поддерживаются также ссылки в справочном стиле: `[label][id]` с определением `[id]: https://example.com` в другом месте.

## Код

Строчный код использует обратные апострофы: `` `inline` ``.

Блоки кода — добавьте язык для подсветки синтаксиса:

`````
```cpp
int main() { return 0; }
```
`````

## Цитаты

```
> A quoted passage.
> Second line.
```

> A quoted passage.
> Second line.

## Таблицы

```
| Name  | Role |
| ----- | ---- |
| Muffin | Editor |
```

| Name | Role |
| --- | --- |
| Muffin | Editor |

## Математика

Строчная математика с одинарными долларами, блочная — с двойными:

```
Inline: $a^2 + b^2 = c^2$

$$\int_0^1 x\,dx = \frac{1}{2}$$
```

## Горизонтальная линия

Три и более дефиса в строке:

```
---
```

---

## Сноски

```
Here is a statement.[^1]

[^1]: The note text.
```

## Метаданные

Блок YAML (`---`), TOML (`+++`) или JSON в самом начале файла разбирается как метаданные и остаётся нетронутым.
