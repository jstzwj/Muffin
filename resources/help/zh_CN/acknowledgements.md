# 致谢

Muffin 站在众多优秀开源项目的肩膀上。

## 核心库

- [Qt 6](https://www.qt.io) —— 应用程序与界面框架。
- [cmark‑gfm](https://github.com/github/cmark-gfm) —— GitHub 风格 Markdown 解析。
- [Tree‑sitter](https://tree-sitter.github.io) 及其语言语法 —— 代码语法高亮。
- [KaTeX](https://katex.org) —— 快速数学公式排版（自带字体）。
- [Nuspell](https://github.com/nuspell/nuspell) —— 拼写检查。
- [ICU](https://icu.unicode.org) —— Unicode 支持。

## 布局与 HTML

- [Yoga](https://github.com/facebook/yoga) —— Flexbox 布局引擎。
- [Lexbor](https://github.com/lexbor/lexbor) —— HTML 解析。

## 图像解码

- [libavif](https://github.com/AOMediaCodec/libavif) 与 [dav1d](https://code.videolan.org/videolan/dav1d) —— AVIF 图像解码。
- [libjpeg](https://www.ijg.org) —— JPEG 解码。
- [libpng](https://www.libpng.org/pub/png/libpng.html) —— PNG 解码。
- [libwebp](https://developers.google.com/speed/webp) —— WebP 解码。

## 拼写检查词典

内置词典取自 [LibreOffice 词典](https://github.com/LibreOffice/dictionaries)（英文部分基于 [SCOWL](http://wordlist.aspell.net/)）以及 [wooorm/dictionaries](https://github.com/wooorm/dictionaries)（其它语种）。
