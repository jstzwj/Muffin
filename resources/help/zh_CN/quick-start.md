# 快速入门

欢迎使用 **Muffin**，一款使用 C++ 和 Qt 构建的快速、原生 Markdown 编辑器。

## 新建或打开文档

- 选择 **文件 → 新建** 创建一个空白文档，或选择 **文件 → 打开** 打开已有的 `.md` 文件。
- **文件 → 打开文件夹** 可在侧边栏打开一个文件夹，方便您浏览和切换文件。
- **文件 → 重新打开已关闭的文件**（`Ctrl+Shift+T`，macOS 为 `⌘+Shift+T`）可恢复最近关闭文件的编辑模式、选区和阅读位置。每个窗口最多记住 32 个文件，退出窗口后清空。重新打开读取磁盘上的最新内容，不会恢复已放弃的未保存修改。
- **偏好设置 → 文件 → 默认以标签页打开文件** 默认开启。从文件管理器或命令行打开文件时，会在已有窗口中打开标签页；关闭后会打开新窗口。「在新窗口打开」命令和命令行 `--new-window` 可单独指定新窗口。

## 编辑视图

- **渲染模式**（默认）显示实时格式化的页面 —— 输入 Markdown，即可看到效果。
- **源码模式** 显示原始的 Markdown 文本。点击左下角 `</>`，或选择 **视图 → 源码模式**（`Ctrl+/`，macOS 为 `⌘+/`）。
- **源码与预览** 在左侧编辑 Markdown，右侧显示只读的原生预览。点击 `</>` 右边的分屏按钮，或选择 **视图 → 源码与预览**；再次点击分屏按钮，返回之前的单栏视图。点击 `</>` 则直接进入单栏源码模式。

拖动中间分隔线可调整两栏大小，阅读位置保持在原文附近。预览标题栏的 **分屏布局** 菜单可选择 **左右分栏**、**上下分栏**，或 **调换源码与预览**。**同步滚动** 按源码位置联动两侧视图，关闭后可分别滚动。每个标签页独立记住视图、分栏方向、顺序、分隔比例和滚动设置，恢复会话时也会保留。两侧共用同一份文档与撤销历史。可在 **偏好设置 → 键盘快捷键** 为分屏命令设置快捷键。

源码和分屏视图中，**专注模式** 淡化其他源码行，**打字机模式** 跟随源码光标所在的实际文字行。预览保持完整显示，位置由同步滚动设置控制；切回所见即所得编辑后，这两个模式恢复在渲染编辑区生效。光标是否始终居中的偏好也适用于源码编辑。

## 编写您的第一份文档

输入 Markdown 即可即时格式化。以下是几个基本要素：

| 您输入的 | 您得到的效果 |
| --- | --- |
| `# 标题` | 一级标题 |
| `**粗体**` / `*斜体*` | **粗体** / *斜体* |
| `- 列表项` | 无序列表 |
| `` `代码` `` | 行内 `代码` |
| `[链接](https://example.com)` | 可点击的链接 |

您还可以插入表格、数学公式（`$E=mc^2$`）、脚注以及代码块 —— Muffin 支持渲染完整的 GitHub 风格 Markdown。

## 导出预设与重复导出

在 **偏好设置 → 导出** 点击 **新建**，可以基于 PDF、HTML、图片、Pandoc 格式或 **自定义命令** 建立命名预设。每个预设独立保存参数，可复制、重命名、排序或移除，原有格式默认设置仍然保留。在 **文件 → 导出 → 导出预设** 中选择预设即可导出。

成功导出后，**使用上次设置导出** 会沿用该次参数并让您选择新位置；**导出并覆盖上次输出** 直接写入上次成功的目标文件。两者都导出当前正文，包括未保存的修改。每个标签页独立记住上次成功的参数和实际主题，关闭标签页后清空。失败或取消会保留原输出文件和上次成功记录。这些命令也可在 **偏好设置 → 键盘快捷键** 中配置快捷键。

自定义命令需要填写可执行程序、参数和不带点号的输出扩展名。程序必须在 `${outputPath}` 生成一个文件。参数可使用以下变量：

| 变量 | 含义 |
| --- | --- |
| `${inputPath}` | 包含未保存修改的临时 UTF-8 Markdown 副本 |
| `${outputPath}` | 临时输出路径，成功后由 Muffin 写入所选目标 |
| `${currentPath}` | 当前文档路径，未命名文档为空 |
| `${currentFolder}` | 文档所在文件夹，未命名文档使用用户主目录 |
| `${fileName}` | 不含扩展名的文档名称 |

例如，选择 Pandoc 为可执行程序后，参数可以填写：`"${inputPath}" -o "${outputPath}" -t docx`。含空格的参数用双引号包围；变量作为字面内容传递，不会自动启动命令行 shell。自定义命令用于生成单个文件；如需模板、目录等内置格式选项，可直接创建相应 Pandoc 格式的预设。

## 实用技巧

- 实时编辑模式粘贴网页或办公软件的 HTML 时，会保留标题、强调、列表、链接和表格。以制表符分隔的电子表格单元格会转换为 Markdown 表格。只需要文字时使用 **编辑 → 粘贴为纯文本**；代码块和源码模式始终按原始文字粘贴。
- 实时编辑模式复制时，同时提供适合富文本软件的 HTML 和适合 Muffin 的 Markdown。**偏好设置 → 编辑器** 可控制粘贴到纯文本软件时是否带 Markdown 语法。
- 在 **偏好设置 → 键盘快捷键** 中搜索命令、录入组合键、处理冲突或恢复默认设置。修改立即生效，下次启动仍然保留。
- 阅读或校对时，使用 **编辑 → 锁定编辑**（默认 `F12`）防止误改。锁定后仍可选择、复制、查找和切换标签页；再次执行可解锁。**偏好设置 → 编辑器 → 锁定编辑** 可选择独立标签页或整个窗口，快捷键可在 **键盘快捷键** 页面修改。
- 在 **偏好设置 → 导出 → PDF** 中配置页眉、页脚、作者和页码。模板支持 `${title}`、`${author}`、`${fileName}`、`${date}`、`${pageNo}`、`${pageCount}`。
- 使用菜单中的“格式”和“段落”命令为文本添加样式，无需记忆语法。
- **编辑 → 查找 / 替换** 可在当前文档中搜索。
- **偏好设置 → 搜索** 可配置文件夹内容搜索和 `Ctrl+P` 文件定位的范围：扩展名、忽略文件／目录规则、隐藏文件，以及是否读取搜索根目录和子目录中的 `.gitignore`、`.ignore`。修改在下一次搜索时生效，与文件打开保护设置独立。
- 忽略规则每行一条，例如 `build/`、`*.bak`、`/drafts/`；支持 `*`、`?`、`**` 和 `!` 例外。`.ignore` 优先于 `.gitignore`，偏好设置中的规则优先于两者。已忽略的目录不会继续扫描，例外规则需要先允许其父目录。扩展名填 `*` 可搜索所有类型，留空则不搜索文件；二进制或不支持的编码仍会跳过。
- 普通内容搜索默认限制单文件 100 MiB，正则搜索另有限制 32 MiB，均可在搜索设置中调整，最大 512 MiB。文件定位不受大小限制；目录替换保留独立的 8 MiB 限制。搜索结果摘要中的**搜索详情**可查看被规则排除或因大小、权限、编码等原因跳过的文件。
- 在 **主题** 中挑选外观 —— Muffin 内置浅色、深色以及“Whitey”三种主题。

完整的语法参考请查阅 [Markdown 参考手册](help:markdown-reference)。
