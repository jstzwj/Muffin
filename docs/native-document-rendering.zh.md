# 原生文档渲染与视觉验收

## HTML 与 Markdown 混排

`MarkdownFlow` 在原始 Markdown AST 上建立借用的渲染关系。独占 HTML 块、
成对出现的 `div`、`section`、`article`、`aside`、`main`、`header`、`footer`、
`nav`、`figure`、`blockquote`、`center` 可以包住后续 Markdown 块。
渲染树负责容器、父子与兄弟关系，原始 AST 继续负责所有权、编辑和源码位置。
样式选择器、继承、块布局、导航索引使用同一份渲染关系。

阅读时不为已配对的标签显示代码栏；移到容器右上、右下边缘可以通过现有
HTML 源码按钮编辑开始或结束标签。标签仍是原文件中的 HTML 节点，文档保存时
不重写它们。未配对或嵌套不合法的边界不吞掉后续正文，保留源码显示入口。
完整 HTML 片段继续由 Lexbor、原生布局和 QPainter 处理。

这不是浏览器 DOM，也没有引入 WebView。当前跨 Markdown 块的投影要求每个
边界 HTML 块只包含一个容器标签；同一块内多个开闭边界尚未投影为跨块容器。
跨块容器的结构或正文改变时会重新生成关系；纯选区更新只刷新所属布局子树。
这轮没有为超大混排容器增加独立的子树虚拟化；此类文档的连续编辑性能仍需
单独压测，普通 Markdown 的现有增量和懒布局路径继续保留。

## SVG

文档图片共用 `SvgDocument`：将 Qt SVG 尚未直接处理的 `feDropShadow` 降解为
高斯模糊、偏移、颜色填充、合成、合并等原生 SVG 滤镜图元。保留输入结果链、
透明度和滤镜区域，源 SVG 文件保持不变。显式区分逻辑目标尺寸和物理像素，
栅格化按 DPR 计算，分配限制作用于实际像素数。
Markdown 与 HTML 图片布局、资源尺寸版本统一使用逻辑尺寸，像素密度增加不会
放大正文中的图片；逻辑尺寸未变时只更新绘制内容。

能力测试检查 100%/125%/150%/200% DPR、目标尺寸、半透明阴影、越过图形边界
的阴影和透明背景。现有 Qt SVG 后端通过这些测试，因此暂不增加其他后端。
这不代表覆盖浏览器的全部 SVG/CSS/动画能力；新的不支持特性应以独立样本复现。

## 页面和文字

主窗口内容区定义主题 CSS 视口，编辑器可用区域定义剩余排版空间，显式的用户
正文宽度优先于主题宽度；侧栏变化不再单独改变主题媒体查询的断点。
独立使用 EditorView 时可以显式指定主题视口，否则沿用自身视口。

字体与中文回退继续通过统一字体解析器处理，CSS 计算字号只缩放一次。
上、下标以共享基线偏移表示，避免 Qt 的脚本对齐再次缩小字体。行内图片使用
非空白对象占位，图片宽度参与居中与右对齐。文字布局、绘制、光标与选区继续
共享实际成形和行盒结果，不另写一套坐标估算。
图片点击使用与绘制相同的矩形，不再把图片旁的空白按最近文字光标算作图片。
字重、行高、段间距和列表缩进继续由计算后的主题样式决定，不对 README
增加特殊字号或间距规则。
