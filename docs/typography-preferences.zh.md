# 字体与排版偏好

在“偏好设置 → 外观 → 字体与排版”中，“字体”“字号”和“标题字号”三组设置始终展开。字体组包含正文字体和代码字体，下拉列表在字体名称旁显示该字体的样例，随界面语言切换：例如中文 `ABC 123 中文`、日文 `ABC 123 日本語`、韩文 `ABC 123 한글`；没有对应翻译时回退为 `ABC 123`。名称保留界面字体，避免符号字体导致名称无法辨认。页面不再单独展示标题、正文和代码预览。字号组包含正文、代码和源码编辑器字号，标题字号以紧凑网格显示 H1–H6。每项默认跟随主题；覆盖值独立保存，切换主题后继续生效，不写入 Markdown，也不修改主题文件。

正文大小会按比例调整主题的文字尺寸，保留标题层级和上下标比例。代码字号、各级标题字号一旦单独指定，就不再跟随正文大小。字号使用逻辑 CSS 像素，之后仍会应用“文本缩放”和视图缩放；例如 20 px 在 125% 文本缩放下显示为 25 px。系统 DPI 由 Qt 处理，不重复计入。原有“文字大小”实际控制的是整套文字比例，现改名为“文本缩放”并显示百分比，已有设置继续保留。

源码编辑器可以指定独立字号；源码字体默认采用主题的代码字体，用户代码字体优先。行内代码和代码块共用代码覆盖。数学字体、图标字体和应用菜单字体保持各自的语义与用途。

外观页面的下拉框收起时，鼠标滚轮和触控板滚动只滚动页面，即使输入框已有焦点也不会改变设置。展开下拉列表后可以滚动浏览选项，点击或使用键盘选择仍会立即保存。

“恢复主题字体”一次清除所有字体及字号覆盖，不改变主题选择或缩放。暂时未安装的字体保留配置，渲染使用平台字体回退；代码字体保留等宽回退。

PDF 和图片导出默认继续使用各自的字体大小与主题设置。需要采用上述覆盖时，在相应导出设置或命名预设中开启“使用编辑器字体设置”。重复导出复用上一次导出的主题快照。HTML 和 Pandoc 格式继续采用各自的样式文件。

实现中 `TypographyOverrides` 仅保存明确选择的值。`RenderTheme` 以未修改的主题为基础计算正文缩放，在私有有效样式表上添加字体和固定字号规则。用户规则具有独立的优先级，因此不依靠堆叠选择器权重覆盖主题。Markdown、HTML、测量、绘制与命中测试使用同一份计算样式；原始样式表和基础引擎不被修改，窗口宽度及媒体条件变化时可以重新投影。

`MuffinTypographyOverridesTest` 覆盖五套内置主题、响应式主题、覆盖优先级、图标字体保护、设置恢复、字体与缩放、布局命中及真实 PNG/PDF 导出。`MuffinDocumentTabsTest --typography` 覆盖偏好设置到多窗口、后台标签页和新标签页的传播，并检查最小窗口宽度下的控件布局；设置 `MUFFIN_TYPOGRAPHY_SCREENSHOT_DIR` 可以保存浅色、深色界面截图。
