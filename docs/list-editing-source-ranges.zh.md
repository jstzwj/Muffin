# 列表源码范围与连续编辑验收

`document/ListItemSource` 以当前 Markdown AST 和 PieceTable 为唯一依据，提供列表项的标记、首行、主段落、子块和完整源码范围。偏移统一使用 UTF-16；首行内的标记偏移相对物理行起点，其余范围为文档绝对偏移。

只有列表项的第一个子节点为段落时，它才是标记旁的正文。`3. 4. 正文` 的外层正文为空，内层标记、正文属于子列表；后续标题、段落、代码块也分别拥有自己的范围。编辑上下文、渲染、剪贴板和重编号均通过这一契约取得边界，不能从物理行起点重新猜测列表层级。

结果按需生成，包含借用的 AST 指针，只在当前文档版本有效。编辑后重新取得结果，不增加逐节点缓存或文本副本。重编号只遍历同级 AST 列表项，遇到显式空行分隔停止，跳过子列表和代码块。

Backspace 与 Delete 合并相邻列表项时，统一调用 `buildMergeListItems`：拼接双方完整主段落，随后依次保留左项、右项的全部子块，以一次源码编辑提交。不再按首行行尾拼接，也不再为子列表单独设置保留分支。标题、后续段落、引用、表格和代码块都使用共享的 `content`、`children`、`item` 范围。

`markerToken` 单独标识数字与分隔符或项目符号，不含填充空白和任务复选框。`listContentPrefix` 按 CommonMark 的标记宽度、填充空白、制表位和外层引用计算续行前缀；右项移动到左项时，仅调整这个容器前缀，保留子块自身缩进与字面内容。转换按行生成结果，避免逐行替换长文本导致反复移动尾部。空标记获得正文时归一化为一个填充列，防止原有行尾空白改变子块归属。

缩进代码块的起点由 AST 给出，它包含代码缩进与字面内容的分界。移动代码块时一并转换这段缩进，避免 Tab 在新列位置上变短后失去代码块语义；字面内容里的 Tab 保留原字符，围栏代码的正文也不展开。测试独立比较合并前后的代码块类型、语言和字面内容。

无主段落且子块与标记同行时，合并后补上块间分隔，避免非 1 开始的有序子列表或缩进代码被解释为普通正文。Delete 在空父项与同行子列表之间仍优先移除一个层级；这是跨父子边界的操作，不是相邻兄弟项合并。Backspace 删除真正的空兄弟项后，光标回到前项最后一个可编辑后代，不落在代码围栏的结束标记上。

撤销前为只有可见文字偏移的光标补齐源码位置；局部重解析后同步更新受影响顶层块的内部节点索引，使恢复的光标和选区可以立即命中布局。

自动验收入口是 `MuffinListEditingSequenceTest`，配合已有的列表缩进、空项退格和鼠标定位测试，覆盖：

- 同行嵌套列表正文开头、中间和末尾的 Enter，以及撤销、重做。
- Delete 合并相邻子项、删除空父项的内层标记，保留正文。
- 多层任务项和含标题、独立段落、代码块的源码归属。
- 双向跨层剪切、真实剪贴板粘贴、选区与光标恢复。
- 带强调标记的中文选区及非零文档起点的源码映射。
- Enter → 中文输入法提交 → Backspace 合并 → 连续撤销。
- 多段落、双代码围栏、任务子列表、引用与表格的双向合并；覆盖不同编号宽度、制表符、空标记和同行嵌套。
- 混合子块的 Delete 合并 → Enter → 中文输入法提交 → 整项缩进/减少缩进 → 双向跨层剪切 → 连续撤销/重做 → 真实剪贴板粘贴。
- 每一步对比完整源码、光标布局命中，以及增量 AST 与全新解析的节点、源码范围、内联文字和列表元数据。
- 自动重编号不修改代码块中的数字。

手工验收时可使用 `3. 4. 正文`、带子列表的任务项和松散有序列表，依次进行点击定位、Enter、Delete、跨层拖选、剪切粘贴、Tab/Shift+Tab、连续撤销和重做；同时检查源码、层级、光标及选区，不应只检查最终文字。
