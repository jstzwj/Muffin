# 块操作手柄

在 **偏好设置 → 编辑器 → 实时渲染 → 显示块手柄** 开启，默认关闭，修改立即应用于所有窗口。该功能用于所见即所得编辑区；源码模式和分屏的只读预览不显示手柄。

将鼠标移到内容上，块左侧显示六点手柄。点击打开菜单，拖动显示插入线，松开后移动到目标位置。拖至视口上下边缘可以自动滚动，`Esc` 取消拖动。点击手柄不会改变原来的文字光标。

标题等级标记与手柄共用左侧留白：悬停到标题时由手柄占用该位置，移开后恢复原有的标题等级标记，不叠加绘制，也不改变正文宽度。

菜单支持在上方／下方插入、复制 Markdown、剪切、创建副本、删除、上移和下移。普通段落及标题还可以转换成正文、一至六级标题、无序／有序／任务列表、引用和代码块；行内 Markdown 保留，标题和列表遵循已有语法偏好。复杂容器的转换入口禁用，避免丢失子块。

顶层的引用、表格、代码块按完整结构操作；跨 Markdown 块的合法 HTML 容器包含起止标签及全部内部内容。列表内可以单独操作列表项，包括子列表中的同级项；移动父项时，其附属段落、代码和子列表一起移动。列表项只能在同一父列表内排序，拖动期间不会切换层级。有序列表遵循已有编号偏好，连续编号时保留列表起始编号；编号宽度变化时同步调整子块缩进。同行嵌套标记（例如 `3. 4. 内容`）回退到完整外层项，避免截断父标记。

暂不支持跨列表拖动、拖入嵌套容器、跨文档拖放、块颜色和永久块链接。移动后的内容仍按普通 Markdown 解析，相邻同类列表可能按 Markdown 语义合为一个列表。

## 结构与历史

- `MarkdownDocument::blockStructure()` 按文档修订号惰性缓存操作单位及源码范围；列表作用域按需建立，直接使用共享的 `ListItemSource` 正文、标记与子块范围。目标只保存节点 ID、修订号、父作用域和索引，不保存 AST 指针。旧菜单、编辑期间失效的拖动和只读状态不能修改新文档。
- `HtmlContainerStructure` 统一提供 HTML 边界识别和配对，渲染与块操作使用相同语义。渲染扫描保留协作式让出，错误标签继续使用原有源码回退。
- `BlockStructure` 生成 PieceTable 编辑计划。移动只删除与插入目标内容，并修改受影响的编号及缩进前缀，不复制两处之间的正文。`SourceTextChange` 记录移动范围及重编号引起的位置变化，让阅读位置跟随其原文。
- `BlockSourceBoundary` 统一检查依赖 EOF 终止的代码围栏、数学块和 HTML 字面块。移动、复制或在其后插入内容时，按需补上闭合标记，避免后面的段落被吞入；补齐的标记与操作一起撤销，不在打开文档时改写用户源码。
- `InlineBlockConversion` 为块菜单和已有标题、列表命令提供共享的源码转换。转换时移除 ATX 起止标记或 Setext 下划线，保留行内 Markdown 的原始拼写；通过当前解析器检查正文是否会变成列表、引用或分隔线，必要时添加转义，并记录双向位置映射。无法无损表达为正文的 HTML 块起始内容会拒绝转换。
- 转换也保护任务标记、引用提示框标记与文档开头的 Front Matter，防止普通文字被解释成额外结构。提示框识别检查原始源码；转义的 `[!NOTE]`、行内代码和加粗中的同样文字不会被误认为提示框。
- `EditorController` 将计划提交给已有异步批量事务和撤销系统。一次移动、删除或复制对应一个撤销步骤；拖动预览和取消不创建历史。键盘上移／下移与手柄使用同一实现。
- `EditorView` 复用布局槽位查找和文档到视口的坐标映射，只绘制一个悬停手柄；没有为各块创建控件。手柄关闭时，悬停和绘制不会建立结构缓存，也不会创建自动滚动定时器。

## 验收入口

`MuffinBlockStructureTest` 覆盖源码范围、嵌套 HTML、列表／代码、Front Matter 保护、无结尾换行、失效目标和稀疏移动；另含引用中的子列表、同行嵌套保护、9／10 编号宽度变化及双向源码位置映射。`MuffinBlockHandleTest` 覆盖鼠标拖动、撤销重做、菜单目标、取消、只读保护、插入后输入及边缘滚动，并连续验收中文输入、子列表排序、父项携带多段落和代码移动、两次撤销／重做及插入新项后输入。另有 125%／150% 显示比例和惰性布局测试变体。

`MuffinDocumentTabsTest --block-handles` 检查真实菜单与偏好设置：设置应用于已有窗口、后台标签和新标签，菜单作用于悬停块而非写作光标所在块。

边界回归另覆盖未闭合围栏／HTML 字面块的移动和复制、在其后新建段落、合法围栏尾部空格、列表内未闭合围栏；转换回归覆盖带闭合 `#` 的标题、以 `>`／`1.`／`---` 开头的标题、多行 Setext、行内格式及双向位置映射。`MuffinBlockHandleTest` 连续执行补齐闭合标记后的移动／复制和标题／正文／列表转换，逐次撤销、重做并校验完整源码。`MuffinParagraphHeadingTest` 同时检查旧命令入口、引用前缀和列表续行缩进。
